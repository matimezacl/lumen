# Lumen (concept)

An interactive quarterly review deck built from a spreadsheet. Open it at https://matimezacl.github.io/lumen/

Drop `Lumen-Q2-2026.xlsx` or `Lumen-Q3-2026.xlsx` (or any CSV with the same columns) onto the page to rebuild every chart and headline. Files never leave your browser.

Lumen Coffee is a fictional company and every figure is invented.
